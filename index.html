AnyMotion Docs

Documentation for AnyMotion — procedural humanoid animation tools for Unity.

Built for robots, low-poly and blocky characters, cartoon characters and horror-styled characters, rather than realistic human models. It also works as a general-purpose prototyping and placeholder animation solution, useful for blocking out gameplay and iterating before final character animation is authored, on any character regardless of its eventual art style.

  • AnimateHumanoid Guide — how to add procedural walk/run/idle animation to a humanoid character.
  • API Reference for generated API documentation.

BoneStretch

O4 (knee pop) from the ik-pop-flip-prevention scout report, second half of the Kovar fix whose first half is SoftReachStart. Off by default and bit-for-bit inert when off — see IkTargetSpaceDriver.ResolveStretchFactor, which returns exactly 1 for every input while this is off, so the solver's own arithmetic is unchanged rather than merely equivalent.

[Tooltip("Lets the leg (or arm) segments grow slightly, and only inside the Soft Reach Start band, so the foot reaches a distant target instead of falling short of it. Off by default: it changes the limb's visible length, which suits stylised characters more than realistic ones. Soft Reach Start alone already removes the knee pop; this recovers the reach that softening gives up.")]
public bool BoneStretch

bool

MaxBoneStretch

O4: bound on BoneStretch, as a fraction of each segment's own bind-pose length rather than of the whole chain, so an unusually short shin is never given a thigh-sized absolute stretch. Applied per segment and reached only at full extension. Capped further by IkTargetSpaceDriver.ResolveStretchCeiling, which is where the measurement behind the 0.05 default and behind the cap itself is written down.

[Tooltip("How much longer a limb segment may become at full extension, as a fraction of its own length. 0.05 adds 5 percent to the thigh and 5 percent to the shin, so the leg reaches 5 percent further and recovers about 60 percent of the reach the softening gives up. Only reached at full extension, and zero at Soft Reach Start. A raised Soft Reach Start narrows the band this has to work in and lowers the value that can be used: above roughly 0.07 at the default Soft Reach Start of 0.90 the limb would start to bend more as it reaches further, so the value is capped there. Has no effect while Bone Stretch is off.")]
[Range(0, 0.1)]
public float MaxBoneStretch

Walks and runs characters across a fixed camera framing, either as an automated sequence over a list of characters and a list of presets, or as one character under manual control. The automated sequence is what a screen recording is cut from; the manual mode is what one preset is designed in.

Remarks

Both modes run outside Play mode and inside it. Outside Play mode DesignScenePreviewDriver calls Tick(float) on every editor update; inside Play mode CodeSmile.AnyMotion.AnimateYourself.Samples.DesignScene.Update() calls it. Neither path uses a UnityEngine.CharacterController, physics, or anything else Play mode alone provides, so both produce the same motion.

Hierarchy contract (R1). This component writes the character root transform, the same way a character controller would. The gait writes the visual root below it. Each entry in Characters is therefore a character root whose AnimateHumanoid sits on a child, not on the entry itself. An entry that carries AnimateHumanoid on the entry object is reported in CodeSmile.AnyMotion.AnimateYourself.Samples.DesignScene.BuildReport() and skipped, because moving that object here and animating it there would be two writers on one transform.

Every character's settings are restored. The automated sequence overwrites the settings of each character it plays, because that is what applying a preset means. The settings each character had when driving started are captured as JSON in CodeSmile.AnyMotion.AnimateYourself.Samples.DesignScene.m_Captured and written back by StopDriving(). The capture is serialized, so a script recompile or a scene reload does not lose it.

Remarks

Mirrors what WalkGait computes for the same speed: the walk step length blended towards the run step length by the run blend weight, times the measured stride reference. It is a separate copy because both inputs it needs are public and the blend itself is not, and because it answers a question about a speed the character is not travelling at yet.

StopDriving()

Stops driving and writes every captured character's settings and active state back. Leaves the camera where the last frame put it.

Tick(float)

Advances the scene by deltaTime seconds: writes the camera transform, places the character being played and hands it its speed. Called by CodeSmile.AnyMotion.AnimateYourself.Samples.DesignScene.Update() in Play mode and by DesignScenePreviewDriver outside it.

public void Tick(float deltaTime)

Remarks

This method does not advance the gait itself. WalkGait advances in its own Update in Play mode and in WalkGaitPreviewDriver outside it, both of which run whether this component exists or not.

Public so a recorder or a verification harness can step the scene at a fixed time step instead of at whatever step the editor or the player happens to produce.

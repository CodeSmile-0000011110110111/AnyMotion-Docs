    Remarks

    CreateInspectorGUI() lists every field by name rather than calling InspectorElement.FillDefaultInspector (the pattern WalkGaitEditor uses), so a new [SerializeField] added to GaitDriver does not appear here automatically — it was missed once already (L01's m_LookAtTarget, caught by the user, not by the compile-check, which cannot see a missing UI Toolkit element). Add a UnityEditor.UIElements.PropertyField for it below when this next happens.

The one Inspector for the whole locomotion system. Presents the settings of the two components AnimateHumanoid owns — WalkGait's parameter groups and GaitDriver's scene wiring — as a single list grouped by what the user is deciding, rather than by which component a field happens to be stored on.

Remarks

Both owned components are hidden from the Inspector (see AnimateHumanoid), so this replaces the two separate inspectors they used to have. Their fields are drawn through their own UnityEditor.SerializedObjects rather than being moved onto AnimateHumanoid: no serialized data changes location, so a character configured before AnimateHumanoid existed keeps every value it had.

Three pairs of fields are deliberately merged into one control, because they were always two halves of one decision: ground contact settings sit next to the ground probe's own layer mask and probe distances; the look-at weights sit next to the look-at target; the arm settings sit next to the two hand targets. One further merge is behavioural rather than cosmetic — see CodeSmile.AnyMotion.AnimateYourself.Editor.AnimateHumanoidEditor.BuildPreviewSection(UnityEngine.UIElements.VisualElement) on the edit-mode preview toggle.

    Class GaitDriver

    Applies the pose produced by WalkGait to the rig through one of the three candidate driver spaces, switchable at runtime so the same character can be compared across all three.

    Syntax
    [DefaultExecutionOrder(1000)]
[RequireComponent(typeof(WalkGait))]
public sealed class GaitDriver : MonoBehaviour
    Remarks

    Runs in LateUpdate with a high execution order, so it runs after the Animator and after Animation Rigging. That ordering is what R7 is about; this component is where a customer would change it.

    All three spaces are bound at once and kept bound, so switching between them costs nothing and a switch cannot be confused with a rebind. The two that are not active write nothing.

    Use this after the rig has been left in an odd state — a script recompile mid-animation, an interrupted preview, or a measurement taken while posed. It is also the correct thing to do before pressing Measure on RigMetrics, although Measure now resolves its own reference pose and no longer depends on the rig being reset first.
